# CTranslate2-Reborn

An unofficial fork of CTranslate2.

Each release has the version number of the upstream release it's based on, followed by `.post1`, `.post2`, `.post3` and so on: for example, `4.8.3.post1`.

[Differences from upstream](https://github.com/BBC-Esq/CTranslate2-Reborn/blob/master/DIFFERENCES_FROM_UPSTREAM.md) lists every change this fork makes, oldest first.

## Installation

```bash
pip install ctranslate2-reborn
```

> Can't be installed alongside upstream's `ctranslate2` package, since both install the `ctranslate2` module. Uninstall `ctranslate2` and use `ctranslate2-reborn` instead.
